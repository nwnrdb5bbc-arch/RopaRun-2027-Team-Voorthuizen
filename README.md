# Sponsor een kilometer - 2027

Interactieve sponsorkaart voor 558 kilometerpunten (km 0 t/m 557). Elke beschikbare kilometer kan voor EUR 10 worden gesponsord.

## Publiceren met GitHub Pages
1. Maak op GitHub een nieuwe repository, bijvoorbeeld `sponsor-een-kilometer-2027`.
2. Upload `index.html` naar de root van de repository.
3. Ga naar **Settings > Pages**.
4. Kies bij **Build and deployment**: **Deploy from a branch**.
5. Kies branch **main** en map **/(root)** en klik **Save**.
6. GitHub toont daarna de openbare URL van de kaart.

## Sponsorformulier
De knoppen op de kaart verwijzen naar:

## Kaarttechniek
De pagina gebruikt Leaflet en OpenStreetMap-kaarttegels. Voor het laden van de achtergrondkaart is internettoegang nodig.
